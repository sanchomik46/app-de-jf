# App de JF

Aplicación React/Vite para el proyecto GLS 29243 BCN — Conveyor Commissioning.

## Web publicada

https://sanchomik46.github.io/app-de-jf/

## Desarrollo local

Requiere Node.js 24 y pnpm 11.25.0 (`corepack enable`).

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

## Compilación

```bash
pnpm run build
pnpm run preview
```

## Publicación

Los cambios en `main` se compilan y publican automáticamente mediante GitHub Actions en GitHub Pages. En Settings → Pages, la fuente debe ser GitHub Actions.

## Alcance de esta versión

Permite buscar actividades y Mark Numbers y consultar material mecánico, eléctrico, documentación y pruebas. Algunos equipos aún muestran datos pendientes; el área de fotografías es una vista preparada, sin subida ni almacenamiento.
